# 簡單行銷 · 營運中台 Dashboard (FY2026)

單頁營運中台，整合資料來源，協助掌握「進度 / 進帳 / 現金流」。

## 資料來源
- **請款 Google Sheet** — 逐月損益、收入分類、現金科目（預計收入 / 應收 / 應付）
- **Trello「公司專案看板」** — 8 階段進度漏斗、執行中/洽談中專案、標籤、到期日、檢查清單（解析自匯出 JSON，236 張卡片）

> 原始 Trello 完整解析存於 `data/trello.json`；中台嵌入精簡版（進行中/洽談中/暫停卡片）。

## 功能區塊
1. **營運總覽** — 年度營收 / 淨利 / 未來待進帳 KPI + 月度營收利潤圖
2. **每月現金流** — 進來的錢 vs 出去的錢（收入 / 成本+費用 / 淨流入）
3. **未來進帳** — 預計收入(已簽未開票) + 應收(已開未收) − 應付(待付外包) = 未來淨進帳
4. **收入 × 月份** — 收入分類 × 月份熱力圖
5. **專案 × 月份** — 接案時間軸
6. **專案進度** — Trello 8 階段漏斗 + 執行中/洽談中專案明細

## 開發
純靜態單檔 `index.html`（Chart.js via CDN）。本機預覽：

```bash
npx serve .
```

部署：Vercel（零設定，靜態）。
